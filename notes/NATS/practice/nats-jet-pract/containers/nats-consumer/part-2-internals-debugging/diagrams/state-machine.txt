  The server maintains these key fields for each consumer:

  ┌─────────────────────────────────────────────────────────────────────────┐
  │                        CONSUMER STATE                                    │
  ├─────────────────────────────────────────────────────────────────────────┤
  │                                                                         │
  │  SEQUENCE TRACKING:                                                     │
  │  ┌───────────────────────────────────────────────────────────────────┐  │
  │  │                                                                   │  │
  │  │  sseq  = 42   ─── Next stream sequence to deliver                 │  │
  │  │                   Points to next undelivered message in stream    │  │
  │  │                                                                   │  │
  │  │  dseq  = 15   ─── Consumer delivery sequence (monotonic)          │  │
  │  │                   Increments with each delivery (incl. redeliver) │  │
  │  │                                                                   │  │
  │  │  adflr = 12   ─── Ack delivery floor                              │  │
  │  │                   All consumer sequences ≤ 12 are acknowledged    │  │
  │  │                                                                   │  │
  │  │  asflr = 40   ─── Ack store floor                                 │  │
  │  │                   All stream sequences ≤ 40 are acknowledged      │  │
  │  │                                                                   │  │
  │  └───────────────────────────────────────────────────────────────────┘  │
  │                                                                         │
  │  PENDING MAP: (messages delivered but not yet acknowledged)             │
  │  ┌───────────────────────────────────────────────────────────────────┐  │
  │  │                                                                   │  │
  │  │  streamSeq:41 → { consumerSeq:13, timestamp:1704067200, dc:1 }    │  │
  │  │  streamSeq:42 → { consumerSeq:14, timestamp:1704067201, dc:1 }    │  │
  │  │                                                                   │  │
  │  │  Key: stream sequence                                             │  │
  │  │  Value: consumer seq, delivery time, delivery count               │  │
  │  │                                                                   │  │
  │  └───────────────────────────────────────────────────────────────────┘  │
  │                                                                         │
  │  REDELIVERY QUEUE (rdq): [41, 42]                                       │
  │  ┌───────────────────────────────────────────────────────────────────┐  │
  │  │                                                                   │  │
  │  │  Messages that need to be redelivered due to:                     │  │
  │  │  - AckWait timeout                                                │  │
  │  │  - Explicit Nak()                                                 │  │
  │  │                                                                   │  │
  │  │  Priority: rdq messages delivered before new stream messages      │  │
  │  │                                                                   │  │
  │  └───────────────────────────────────────────────────────────────────┘  │
  │                                                                         │
  │  REDELIVERY COUNTS (rdc):                                               │
  │  ┌───────────────────────────────────────────────────────────────────┐  │
  │  │                                                                   │  │
  │  │  streamSeq:41 → 2   (delivered twice, not yet acked)              │  │
  │  │  streamSeq:42 → 1   (first delivery)                              │  │
  │  │                                                                   │  │
  │  │  When rdc[seq] >= MaxDeliver → message is dropped/dead            │  │
  │  │                                                                   │  │
  │  └───────────────────────────────────────────────────────────────────┘  │
  │                                                                         │
  └─────────────────────────────────────────────────────────────────────────┘

  │  └─────────────────────────────────────────────────────────────────┘    │
  │                                                                         │
  │  After acking M1:                                                       │
  │  ┌─────────────────────────────────────────────────────────────────┐    │
  │  │  pending={2→{cs:2}, 3→{cs:3}}                                   │    │

  │  └─────────────────────────────────────────────────────────────────┘    │
  │                                                                         │
  │  After acking M2 (gap closed):                                          │
  │  ┌─────────────────────────────────────────────────────────────────┐    │
  │  │  pending={}                                                     │    │

═══════════════════════════════════════════════════════════════════════════════
                        MAXACKPENDING FLOW CONTROL
═══════════════════════════════════════════════════════════════════════════════

  MaxAckPending = 3

  ┌──────────────────────────────────────────────────────────────────────┐
  │                                                                      │
  │  Time ──────────────────────────────────────────────────────────►    │
  │                                                                      │
  │  pending.size()                                                      │
  │       │                                                              │
  │     3 ├───────────────────────LIMIT REACHED!─────────────────────    │
  │       │           ╱╲              ╱╲                                 │
  │     2 ├──────────╱──╲────────────╱──╲────────                        │
  │       │         ╱    ╲          ╱    ╲                               │
  │     1 ├────────╱──────╲────────╱──────╲──────                        │
  │       │       ╱        ╲      ╱        ╲                             │
  │     0 ├──────────────────────────────────────                        │
  │       └───────────────────────────────────────►                      │
  │           D1  D2  D3  A1  D4  A2  A3  D5  D6                         │
  │                                                                      │
  │  D = Deliver, A = Ack                                                │
  │                                                                      │
  │  At D3: pending={1,2,3}, size=3=MaxAckPending                        │
  │         → Server STOPS delivering!                                   │
  │                                                                      │
  │  At A1: pending={2,3}, size=2 < MaxAckPending                        │
  │         → Server delivers D4                                         │
  │                                                                      │
  └──────────────────────────────────────────────────────────────────────┘
