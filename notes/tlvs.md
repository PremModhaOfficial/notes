# TLVs
#IEEE standard

| TLV Type           | Real Meaning Example                     |
| ------------------ | ---------------------------------------- |
| Chassis ID         | Device’s MAC address or hostname         |
| Port ID            | The interface name (e.g., Gi0/1)         |
| TTL                | How long info should be considered valid |
| System Name        | Hostname of the neighbor                 |
| System Description | OS, version, vendor                      |
| Port Description   | Description of the port                  |
| Capabilities       | What the device can do (switch, router)  |
| Management Address | IP used for managing the neighbor        |
