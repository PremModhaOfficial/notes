# VM

- VM is a Software simulation that can perform what an pysical machine can perform but doent have a physical form


## Types of Vertual Machines
# Hardware based | System Based
- VMware, vertualBox, KVM are Hardware based vertual machiens
- they logically divide and isolate hardware
## Why
- increase the efficiency of hardware utilazation.
- System admin terminologies hardy a programmers job
# Application Based | Process Based
- JVM, PVM (perl), CLM (common language runtime -.NET)
- Acts as runtime engines to run a perticular programming language
