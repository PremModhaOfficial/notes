# netstat
- info for your network traffic
- what ports are using ehat service

## FLAGS
- p prosses ids
- u udp
- t tcp
- a all (states like listen+rest)
- n number values only
- r routing info
- e extended info like inode
- l listening ports
- s statictics like rx-tx etc
