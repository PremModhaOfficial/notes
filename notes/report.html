Performance & Benchmarking

  • JMC: Profile applications with Java Mission Control and its Flight Recorder to find bottlenecks.
  • JMH: Use the Java Microbenchmark Harness for accurate performance testing.

Memory & Data Structures

  • Data Structures: Choose ArrayList for fast access, LinkedList for fast modifications, and HashMap for quick lookups.
  • Coding Choices: Use primitives over objects to save memory. Use StringBuilder for efficient string concatenation.

Advanced JVM Topics

  • GraalVM: Compile Java apps to native executables for fast startup and low memory with the Native Image builder.
  • JVM Languages: The JVM runs any language that compiles to bytecode, such as Scala and Kotlin. Inspect bytecode with the javap tool.
