# statements

- Command to be executed
  * variable declaration
  * variable mutation
  * method envocation

## Expression Statement
- count = 23;
- getCount();
- count++;
## Declaration Statement
- int count = 23;


## Expressions
- evaluates to a single value
- involves 
  * literals
  * Variables
  * Operators
  * methodcalls
> [!note] Example
> ```java
> int count = x * getCount();
> ```
> this contains 4 exprs
> 1. x
> 2. getCount()
> 3. x * getCount()
> 4. count = x * getCount()
